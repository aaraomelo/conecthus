# Backend — NestJS

Task management API built with **NestJS 12**, **Prisma 7**, **PostgreSQL**, **Redis** (cache) and **MQTT** (real-time notifications).

## Stack

| Concern           | Technology                              |
| ----------------- | --------------------------------------- |
| Framework         | NestJS 12 (Express, ESM)                |
| Persistence / ORM | PostgreSQL 16 + Prisma 7                |
| Cache             | Redis (via cache-manager + keyv-redis)  |
| Messaging         | MQTT (Eclipse Mosquitto)                |
| Auth              | JWT (stateless bearer token)            |
| Validation        | class-validator + class-transformer     |
| API docs          | Swagger/OpenAPI (at `/api/docs`)        |
| Tests             | Vitest (unit) + supertest (integration) |
| Containerization  | Docker / Docker Compose                 |

## Project structure

```text
src/
├── main.ts             # Bootstrap: prefix /api, CORS, ValidationPipe, Swagger
├── app.module.ts       # Root module + Redis cache + global JwtAuthGuard
├── prisma/             # PrismaModule: PrismaService (driver adapter @prisma/adapter-pg)
├── auth/               # register/login, JWT guard, @Public() and @CurrentUser()
├── users/              # GET/PATCH /users/me (profile cached in Redis)
├── tasks/              # CRUD + filters, list cached, MQTT notifications on mutations
├── mqtt/               # MqttService (publishes to notifications/{userId})
├── common/             # Shared helpers (sanitize-user)
└── generated/prisma/   # Prisma Client (generated by `prisma generate`)
```

## Requirements

* Node.js 20+ (24 recommended)
* PostgreSQL 16, Redis 7, and an MQTT broker (or just run the docker-compose infra)
* Docker + Docker Compose (recommended)

## Configuration

Copy `.env.example` to `.env` and adjust:

```bash
cp .env.example .env
```

Key variables:

| Variable         | Default                          |
| ---------------- | -------------------------------- |
| `DATABASE_URL`   | `postgresql://...localhost:5432` |
| `REDIS_URL`      | `redis://localhost:6379`         |
| `MQTT_URL`       | `mqtt://localhost:1883`          |
| `JWT_SECRET`     | `dev-secret-change-me`           |
| `JWT_EXPIRES_IN` | `7d`                             |

> The Prisma CLI reads `DATABASE_URL` through `prisma.config.ts`.

## Running locally

### 1. Infrastructure (PostgreSQL, Redis, MQTT)

```bash
docker compose -f ../docker-compose.yml up postgres redis mqtt
```

### 2. Dependencies, database and start

```bash
npm install
npx prisma migrate deploy
npm run start:dev
```

API: http://localhost:3000/api

Swagger docs: http://localhost:3000/api/docs

## API

* `POST /api/auth/register` — public
* `POST /api/auth/login` — public
* `GET|PATCH /api/users/me` — protected (cached profile)
* `GET /api/tasks` — protected, cached, filters: `status`, `dueDateFrom`, `dueDateTo`, `search`, `page`, `pageSize`
* `POST /api/tasks` — protected, publishes a task notification to `notifications/{userId}` through MQTT
* `GET /api/tasks/:id` — protected
* `PATCH /api/tasks/:id` — protected
* `PATCH /api/tasks/:id/done` — protected
* `DELETE /api/tasks/:id` — protected

All endpoints except `auth/*` require `Authorization: Bearer <token>`.

## Docker

```bash
docker build -t conecthus-backend .

# or from the repository root:
docker compose up --build backend
```

The image entrypoint runs `prisma migrate deploy` before starting the application, and Docker Compose waits for the PostgreSQL, Redis and MQTT health checks before starting dependent services.
